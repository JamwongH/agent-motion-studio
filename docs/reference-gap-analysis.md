# 对照参考片：能力差距与实现路线

目标是 AI 教程账号：真人讲解、独立演示画面、约一分钟的视频。参考片的价值在于材料统一、视线引导和真人/案例接力，而不是商品题材本身。

| 参考效果 | 上游提供什么 | 本分支第一版 | 后续补齐 |
| --- | --- | --- | --- |
| 红字拼贴、纸张背景 | 动效制作规范、字体与 Three.js 工作方式 | 横线纸、红字拼贴组件、颜色管理 | 真正透明拼贴、贴纸资产、材质包 |
| 真人全幅缩到角落 | 口播驱动制作、RVM 抠像工具 | 圆形/圆角小窗、位置与取景调节 | 抠像检查、透明视频配对、字幕安全区域 |
| 软件录屏透视与放大 | 屏幕空间与交接数学指导 | 真实素材贴图、Three.js 透视、焦点缩放 | 操作标注、光标强调、多个步骤的焦点编排 |
| 撕纸章节 | 按任务编写转场的制作流程 | 绝对时间驱动的不规则撕纸 | 纸纤维材质、前后镜头接力与高级转场库 |
| 案例插入、修改前后对照 | 通用镜头设计与素材使用规范 | 两路素材对照与布局选择 | 整片多轨、逐路源时间与连续原声 |
| 键盘/耳机 CG 等案例 | 不能凭包装代码得到案例本身 | 承载已有图片/视频 | 独立生成或制作 CG；B-roll 作为镜头提供方 |
| 可复用的个人风格 | Skill 可规范风格，但不是可视化资产管理器 | 参数封装、素材绑定、风格快照、JSON、独立镜头 | 时间线编辑、组件版本迁移、完整导出与验收 |

先打通“组件 → 实时预览 → 保存封装 → 独立镜头”，再建立整片时间线；否则每次视频仍要重新写布局。

B-roll Loop Engineering 适合在后续阶段提供独立解释镜头和返修检查。接口应接收镜头意图、时长、视觉风格和素材需求，返回镜头源文件/素材与验收记录。人物原声和整片时间由 Studio 统一控制，避免两个流程互相覆盖。当前未复制或集成 B-roll 的代码，也未声称整片自动复刻参考片。
